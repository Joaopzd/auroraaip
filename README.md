# Aura Planner

"Crie um aplicativo de assistente pessoal e organização de rotina. A interface deve ser moderna e minimalista, utilizando uma paleta de cores baseada em azul escuro (#1D2344) para o fundo e detalhes em dourado/amarelo (#F7C534) para botões de ação. O app deve ter uma barra de navegação inferior com três abas: 1. 'Meu Dia' (com a principal prioridade do dia em destaque e progresso de tarefas), 2. 'Semana' (uma visão limpa dos dias da semana para organizar blocos de rotina) e 3. 'Listas' (focada em listas de compras e notas rápidas). Inclua um botão flutuante de chat para interagir com um assistente de IA.
